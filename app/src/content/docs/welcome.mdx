# Welcome to CCResDoc

CCResDoc is a documentation browser for selected local Claude and Codex resources.

The Rust generators populate this site with:

- **Claude** — `CLAUDE.md`, commands, skills, and agents
- **Codex** — `AGENTS.md`, config, agent definitions, hooks, rules, and skills

Enable either source in Settings; generated detail pages appear under the corresponding permanent Claude or Codex category.
